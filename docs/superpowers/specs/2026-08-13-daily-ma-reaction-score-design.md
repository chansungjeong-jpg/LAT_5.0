# 이평선 트레이딩 시스템 — 일봉 이평선 반응 점수 설계

작성일: 2026-08-13

## 1. 목적

Watchlist 종목 중 이미 과도하게 상승한 종목이 아니라, 일봉 이평선에서 의미 있게
반응해 매수할 수 있는 좋은 자리를 찾는다.

이평선 배열 자체보다 가격이 이평선에서 보인 `접근 → 지지/돌파 → 종가 확인`의
상태 전환을 평가한다.

## 2. 기본 원칙

- 일봉 5·20·60선은 단순이동평균(SMA)을 사용한다.
- 계산에는 평가 시점까지 완료된 일봉만 사용한다.
- 당일 가장 강한 대표 반응 하나만 기본점수로 채택한다.
- 동일 현상의 중복 가점을 금지한다.
- 골든크로스는 단독 매수 신호가 아니라 반응 품질 보너스다.
- 거래량은 전체 위치 점수에서 가장 높은 비중을 유지한다.
- 이격도·상단 매물대·손익비는 점수와 별개의 Hard Block이다.

## 3. 일봉 이평선 반응 점수

일봉 이평선 반응 항목은 최대 20점이며, 음수 감점이 가능하다.

### 3.1 대표 반응 기본점수

| 우선순위 | 반응 | 점수 |
|---:|---|---:|
| 1 | 60일선 상향 관통 후 강한 양봉 마감 | +10 |
| 2 | 20일선 부근 조정 후 20일선 위 양봉 회복 | +8 |
| 3 | 전일 5일선 종가 이탈 후 당일 종가 회복 | +6 |
| 4 | 5일선 위 종가 유지 | +3 |
| 5 | 의미 있는 이평선 반응 없음 | 0 |
| 6 | 5일선 종가 이탈 | -4 |
| 7 | 20일선 종가 이탈 | -8 |

여러 반응이 동시에 성립하면 가장 높은 우선순위 하나만 선택한다.

### 3.2 반응 품질 보너스

| 확인 요소 | 점수 |
|---|---:|
| 양봉 몸통 강도가 최근 20개 완료 일봉의 상위 20% | +3 |
| 종가가 당일 고가 부근에서 마감 | +2 |
| 반응한 이평선의 기울기가 상승 | +3 |
| 20일선이 60일선을 상향 교차한 골든크로스 | +2 |

대표 반응과 품질 보너스 합계는 최대 20점으로 제한한다.

## 4. 판정 정의

### 4.1 20일선 반등

```text
당일 저가가 20일선 근처까지 접근
+ 당일 종가가 20일선 위
+ 당일 양봉
= 20일선 반등
```

근접 여부는 고정 퍼센트가 아니라 ATR로 정규화한다. 초기 판정 범위는
`저가와 20일선의 거리 <= 0.25 ATR`이다.

### 4.2 60일선 상향 관통

```text
전일 종가 <= 전일 60일선
+ 당일 종가 > 당일 60일선
+ 당일 양봉
+ 양봉 몸통 강도 조건 충족
= 60일선 상향 관통 장대양봉
```

장대양봉은 절대 상승률이 아니라 `몸통 / ATR`과 최근 20일 몸통 백분위를 사용한다.

### 4.3 5일선 유지·이탈·회복

```text
5일선 유지: 당일 종가 >= 당일 5일선
5일선 이탈: 당일 종가 < 당일 5일선
5일선 회복: 전일 종가 < 전일 5일선 AND 당일 종가 >= 당일 5일선
```

장중 저가만 5일선을 하회하고 종가가 회복한 경우에는 이탈 감점을 적용하지 않는다.
5일선 이탈은 즉시 제외가 아니라 감점이며, 다음 거래일 회복 시 회복 점수로 재평가한다.

### 4.4 종가 강도

당일 고가와 저가가 다를 때 종가 위치를 다음처럼 정규화한다.

```text
close_position = (종가 - 저가) / (고가 - 저가)
```

`close_position >= 0.70`이면 고가 부근 마감으로 본다.

## 5. 전체 위치 점수 100점

| 항목 | 배점 |
|---|---:|
| 거래량·거래대금 | 30 |
| 60분봉 EMA60·EMA120 위치 | 20 |
| 일봉 SMA5·SMA20·SMA60 반응 | 20 |
| 주봉 추세 | 10 |
| 주봉·일봉·60분봉 정규화 기울기 | 10 |
| 최근 5개 완료 일봉의 양봉 개수 | 5 |
| 일봉 추세 지속성 | 5 |
| 합계 | 100 |

현재 별도 `golden_cross +3` 구현은 이 설계 구현 시 제거하고, 일봉 반응 품질의
`+2`로 이전한다.

## 6. Hard Block

점수가 높아도 다음 조건은 BUY를 제한한다.

- 단기 또는 일봉 이격도 과열
- 상단 매물대가 너무 가까움
- 손익비 `RR < 1.5`
- 필수 가격·거래량·이평선 데이터 누락

5일선 이탈은 Hard Block이 아니다. 감점 후 WATCH 또는 재평가 대상으로 남긴다.

## 7. 결과 출력

종목별 결과에는 총점뿐 아니라 다음 근거를 표시한다.

```text
대표 반응
대표 반응 점수
품질 보너스 목록
SMA5 / SMA20 / SMA60 값과 기울기
5일선 유지 / 이탈 / 회복 상태
골든크로스 여부
거래량 점수
이격도 상태
상단 매물대와 RR
최종 BUY / WATCH / REJECT
```

## 8. 검증 원칙

- 피봇과 이평선은 완료된 봉만 사용해 룩어헤드를 방지한다.
- 각 반응은 독립 테스트로 검증한다.
- 대표 반응 중복 방지 테스트를 둔다.
- 5일선 이탈 다음 날 회복 시나리오를 별도로 검증한다.
- 점수 통과와 Hard Block 통과를 별도 테스트한다.
- 백테스트에서는 기존 위치 점수와 새 이평선 반응 점수를 동일 기간에 비교한다.
