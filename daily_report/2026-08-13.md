## RSI 확정 정책

- RSI(14)는 보조지표다.
- Wilder 방식으로 완료된 일봉 데이터만 사용한다.
- 정상 시 `rsi14` 수치만 표시한다.
- 계산 불가 시 다음 형식으로 기록한다.

```json
{
  "rsi14": null,
  "unknown_fields": ["rsi14"]
}
```

- RSI는 점수·게이트·WATCH·Hard Block·`entry_eligible` 판정에 사용하지 않는다.
- RSI 회복, 과매수, 다이버전스, 약화 상태를 자동 판단하지 않는다.
- 최종 RSI 해석은 사용자가 차트와 함께 판단한다.

6. 기존 주도주·Watchlist 종목의 매수 위치 점수 산출을 우선한다.
7. 테마별 종목 랭킹 모듈은 보류하고, 테마는 분류 태그로만 유지한다.

- 거래량 점수와 거래량 변화율을 가장 우선적으로 보여준다.

- 일봉·60분봉 RSI(14)는 판단 없이 수치만 표시한다.
- 이격도, 매물대, 손익비, Hard Block, `entry_eligible` 근거를 함께 표시한다.
- 종목별 상세 화면에서 일봉·60분봉 차트와 점수 구성요소를 확인할 수 있게 한다.
- 시장·섹터·주도주 필터는 관찰 범위 선택용으로만 사용한다.
- 테마별로 매매 위치가 좋은 종목을 순위화한다.
- 주문 실행과 자동 알림은 대시보드 범위에 포함하지 않는다.

현재 우선순위는 테마별 랭킹이 아니라 종목별 매수 위치 점수와 Markdown 리포트다.

- 방산
- 바이오
- 2차전지

각 테마에는 `1위~N위`, 종합점수, 거래대금, 거래 상승률, 핵심 근거,
